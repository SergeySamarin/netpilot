# NetPilot

Программа для Windows, которая управляет обходом блокировок YouTube, Discord и других сервисов в России. Внутри — [zapret](https://github.com/bol-van/zapret) в сборке [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube), а NetPilot берёт на себя всё, что обычно делается через bat-файлы и консоль.

## Что умеет

- **Включить обход в пару кликов** — скачивает zapret, ставит службу Windows, включает и выключает её.
- **Подобрать стратегию** — сам перебирает все стратегии zapret и показывает, с какими открываются YouTube и Discord. Рекомендует одну, чтобы не гадать.
- **Проверить видео YouTube** — открывает плеер YouTube и смотрит, где видео тормозит или зависает. Глубокий подбор проверяет видео на лучших стратегиях.
- **Сервисы галочками** — какие сайты пускать через обход, свои домены и исключения, без правки текстовых файлов.
- **QUIC в браузерах** — если обход с ним не справляется, его можно выключить одной кнопкой.
- **Обновлять zapret** — новая версия скачивается с GitHub, ваши списки и настройки переносятся, можно откатиться.
- **Автозапуск** — служба стартует вместе с Windows, либо NetPilot сам включает обход при входе и не включает его за границей.
- **Значок в трее** — видно, работает ли обход, включить или выключить можно в два клика.
- **Журнал для поддержки** — если что-то не работает, одна кнопка соберёт файл с подробностями.

## Установка

1. Скачайте `NetPilot_…_x64-setup.exe` со страницы [Releases](https://github.com/SergeySamarin/netpilot/releases/latest).
2. Запустите. Windows может показать «Система Windows защитила ваш компьютер» — у программы нет платного сертификата издателя. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Установка идёт только для вашего пользователя и не требует прав администратора.

Нужна Windows 10 или 11, 64 бита.

## Первый запуск

NetPilot предложит скачать zapret с GitHub или указать папку, где он уже лежит. Дальше — «Подобрать стратегию» на главной вкладке: через пару минут обход будет включён.

Действия со службой zapret (включить, выключить, сменить стратегию) требуют прав администратора — Windows спросит разрешение.

**Антивирус** может ругаться на zapret: драйвер WinDivert перехватывает сетевой трафик, и некоторые антивирусы считают это подозрительным. Это ложное срабатывание; при необходимости добавьте папку zapret в исключения.

## Обновления

NetPilot раз в сутки проверяет новую версию на GitHub. Если она есть — появится плашка, обновление ставится кнопкой «Обновить» в «Настройках» → «О программе». Обновления подписаны: программа не поставит файл, подменённый по дороге.

## Удаление

«Параметры Windows» → «Приложения» → NetPilot → «Удалить». Программа уберёт свою задачу автозапуска и спросит, что сделать со службой zapret: удалить её или оставить работать как обычный zapret.

## Какие запросы делает программа

- **GitHub** — новые версии zapret и NetPilot.
- **YouTube, Discord и серверы смайлов для чатов** — проверки, открываются ли сервисы.
- **api.country.is / ipinfo.io** — определение страны по IP, только в режиме автозапуска «Через NetPilot».

Программа ничего не отправляет о вас. Журнал для поддержки собирается только по кнопке и остаётся у вас на компьютере.

## Сборка из исходников

Нужны Node.js, Rust и Microsoft C++ Build Tools.

```
npm install
npm run tauri dev     # запуск в режиме разработки
npm run tauri build   # установщик в src-tauri/target/release/bundle/nsis
```
